
## Evolution and efficiency of category hierarchies

This repository contains code and data for Evolution and efficiency of category hierarchies across languages.

## Folder structure

#### analysis
This folder contains model simulation and case study analysis scripts.

#### data
This folder contains data for analyses and scripts used to create some of them.

#### output
Figures, tables and results files generated by the analysis scripts.

## Requirements

From within R, run

`> renv::restore()`

to install packages used by the code in this repository.

This code was developed using Python 3.14. See `requirements.txt` for a full specification of the environment used.

## Downloading large files

Large files not uploaded to this repository need to be downloaded from [Zenodo](https://zenodo.org/records/24151086). This repository contains `gbif_quercus.csv` and it must be placed in `data` folder to reproduce the analyses.

## Reproducing results

To reproduce tables and figures in the manuscript, follow the steps below.

1) Run `run_simulation_sequential.py` and `run_simulation_simple.py` in `analysis` folder to run sequential and simple model simulations. It needs to be run from the command line to enable parallel processing. It takes about 20 minutes to finish running `run_simulation_sequential.py`.

2) Run `plot_simulation_results.ipynb` in `analysis` folder to create plots for simulations. It produces Figures 4-7 and 12 in the main text and Table S1 in the Supplementary Material. 

3) Run `scrape_naeb.py` and `read_oakoccurrence.R` in `data/scripts` folder to prepare data for oak and acorn domain analysis. `scrape_naeb.py` needs to be run from the command line. It takes about 10 minutes to finish running `scrape_naeb.py` and 10 minutes to finish running `read_oakoccurrence.R`.

4) Run `case_study_analysis.Rmd` in `analysis` folder to run analysis for oak and acorn domains. It takes about 3 hours to finish running Bayesian regression analysis. It produces Figures 8-11 in the main text and Table S2-3 in the Supplementary Material.
